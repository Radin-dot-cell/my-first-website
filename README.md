### Speak. Connect. Inspire.

## 🌟 Project Overview

THE ENGLISH SOCIETY is a modern, responsive English Club website designed to represent a creative and welcoming university community.

The website showcases club activities, upcoming events, team members, gallery, testimonials, and membership opportunities through a premium editorial-style design.

## ✨ Features

- Modern and interactive homepage.
- About the club section.
- Club activities and programs.
- Upcoming events with registration interactions.
- Membership benefits section.
- Team member profiles.
- Interactive image gallery with lightbox.
- Student testimonials with editable sample content.
- Contact and membership form.
- Responsive mobile navigation.
- Smooth scrolling and scroll animations.
- Animated statistics counter.
- Back-to-top button.
- Active navigation highlighting.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Font Awesome / Lucide Icons
- Unsplash Images

**No React, Next.js, frameworks, or build tools required.**

## 🚀 Getting Started

No installation or additional setup is required.

### Run Locally

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.
3. Open `index.html` in any modern web browser.

### Deploy with GitHub Pages

1. Upload `index.html` to your GitHub repository.
2. Go to **Settings → Pages**.
3. Select your deployment branch (`main`).
4. Select the root directory (`/`).
5. Click Save.

Your website will be published using GitHub Pages.

## ⚙️ Customization

All website content can be customized directly inside `index.html`.

You can edit:

- Club name and descriptions.
- Hero section content.
- Membership statistics.
- Event titles, dates, and locations.
- Team member information and images.
- Gallery images.
- Testimonials.
- Contact details and social media links.

Replace all sample content and placeholder images with actual club information before publishing.

## 📩 Contact & Membership

The contact form includes basic client-side validation.

**Note:** Since this is a standalone frontend project, form submissions are not automatically stored or delivered. A backend or form service such as Formspree is required for actual submissions.
